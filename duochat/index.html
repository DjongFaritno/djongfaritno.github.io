MAKE YOURSELF AT HOME

Atur sedikit.
Nyaman seharian.

Akun pribadi, toko, komunitas, sampai kerjaan. Semuanya punya tempat, tanpa bikin ruang ngobrolmu terasa penuh.

01

Dua akun WA? Bisa.

Buka dua akun dari layanan yang sama, atau campur layanan sesukamu. Tiap akun punya sesi login sendiri.

↔
02

Yang privat, diburamin.

Pilih pesan, preview, nama, foto profil, media, atau kolom ketik. Pengaturannya berlaku bersama; tombol Blur tetap terpisah per panel. Hover untuk lihat sebentar.

◌
03

Tinggal sebentar? Kunci dulu.

Pakai password DuoChat, Windows Hello, atau Touch ID pada perangkat yang mendukung. Bisa ikut terkunci saat layar dikunci, sleep, atau kamu sedang nggak aktif.

⌑
04

Lagi fokus? Bikin lega.

Sembunyikan header dan sidebar, atau buka fullscreen. Dekatkan mouse ke tepi kiri saat perlu memilih akun. Kedua panel tetap di tempatnya.

⤢
05

Warna dan bahasa, pilih sendiri.

White, Dark, atau Auto. Bahasa Indonesia atau English. Pilihan bahasa tersimpan dan berubah langsung, tanpa login ulang.

◐
06

Aktif kalau memang perlu.

Jeda akun tambahan atau pilih Tetap aktif untuk menjaga koneksi saat pindah panel. Cek pembaruan tersedia langsung di aplikasi.

◎

DARI UNDUH KE OBROLAN

Pasang dulu.
Habis itu, santai.

Pilih sistem operasimu. Setelah terbuka, tambahkan akun dan pilih dua yang mau kamu pakai bareng.

  1. Taruh di Applications.

    Buka file .dmg, lalu seret DuoChat ke folder Applications. Jalankan aplikasi dari sana.

  2. Muncul “DuoChat Not Opened”? Pilih Done.

    Jangan pilih Move to Trash jika ingin melanjutkan pemasangan.

  3. Buka Privacy & Security.

    Masuk ke System Settings → Privacy & Security. Gulir ke bagian Security, lalu klik Open Anyway untuk DuoChat.

  4. Konfirmasi Open Anyway.

    Di dialog berikutnya, pilih Open Anyway. Jika diminta, gunakan Touch ID atau Use Password… dan kata sandi administrator Mac.

Lanjutkan hanya jika file berasal dari sumber yang kamu percaya. Ini konfirmasi untuk DuoChat; tidak perlu mematikan Gatekeeper.

  1. Buka file installer.

    Unduh file Windows x64 Setup.exe, kemudian jalankan.

  2. Periksa konfirmasi keamanan.

    Jika SmartScreen muncul, pastikan sumber unduhan benar dan periksa checksum di halaman rilis. Untuk file yang kamu percaya, pilih More info → Run anyway jika tersedia.

  3. Ikuti pemasangan.

    Selesaikan langkah installer, lalu buka DuoChat melalui Start Menu atau shortcut aplikasi.

Nama file dan perintah pemasangan akan tampil setelah rilis terbaru diperiksa. Kamu juga bisa membuka halaman rilis GitHub.

  1. Unduh AppImage.

    Unduh AppImage melalui tombol di atas. Simpan DuoChat.AppImage ke folder pilihanmu.

  2. Izinkan file dijalankan.

    Buka terminal di folder tempat file disimpan, lalu jalankan:

    chmod +x DuoChat.AppImage
./DuoChat.AppImage

  3. Mau masuk menu aplikasi Fedora?

    Unduh install-fedora.sh dari halaman rilis v…, simpan bersama AppImage, lalu jalankan:

    bash install-fedora.sh

    Jika FUSE belum tersedia, coba AppImage dengan opsi --appimage-extract-and-run.

SETELAH TERBUKA

Klik +, pilih layanan, lalu beri nama akun. Pilih akun dari menu panel untuk login lewat halaman resminya. Aktifkan Izin bila ingin memakai kamera, mikrofon, atau notifikasi. Bahasa aplikasi bisa diganti lewat header atau menu DuoChat → Language / Bahasa.

BEBERAPA HAL KECIL

Eh, satu lagi…

Ini aplikasi resmi dari penyedia layanan?

DuoChat adalah aplikasi independen yang menampilkan web resmi layanan dalam satu jendela. Kamu bisa memakai beberapa akun dengan sesi terpisah. DuoChat tidak berafiliasi dengan penyedia layanan tersebut.

Bisa telepon dan video call?

Panggilan mengikuti fitur web layanan dan perangkatmu. Izin kamera/mikrofon tersedia per akun. Pilih Tetap aktif untuk menjaga koneksi saat akun keluar dari panel; menjeda akun akan menghentikan panggilannya.

Chat saya disimpan di mana?

Sesi login disimpan lokal. Tiap akun punya profil sendiri, termasuk dua akun dari layanan yang sama. DuoChat tidak menyediakan server chat; pesan mengikuti sistem layanan masing-masing.

Blur dan kunci bedanya apa?

Blur menyamarkan bagian yang dipilih sambil tetap membiarkan chat dipakai. Tutup sementara menyembunyikan satu panel. Kunci menutup tampilan DuoChat dan meminta verifikasi untuk membukanya. Password aplikasi tidak mengenkripsi cookies atau cache sesi di komputer.

English juga mengganti bahasa chat?

Pilihan bahasa mengubah tampilan DuoChat, termasuk menu dan pengaturannya. Bahasa situs layanan dan isi percakapan mengikuti pengaturan layanan masing-masing.
