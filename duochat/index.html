DARI UNDUH KE OBROLAN

Pasang dulu.
Habis itu, santai.

Pilih sistem operasimu. Setelah aplikasi terbuka, tinggal hubungkan akun WhatsApp dan Telegram.

  1. Taruh di Applications.

    Buka file .dmg, lalu seret DuoChat ke folder Applications. Jalankan aplikasi dari sana.

  2. Muncul “DuoChat Not Opened”? Pilih Done.

    Jangan pilih Move to Trash jika ingin melanjutkan pemasangan.

  3. Buka Privacy & Security.

    Masuk ke System Settings → Privacy & Security. Gulir ke bagian Security, lalu klik Open Anyway untuk DuoChat.

  4. Konfirmasi Open Anyway.

    Di dialog berikutnya, pilih Open Anyway. Jika diminta, gunakan Touch ID atau Use Password… dan kata sandi administrator Mac.

Lanjutkan hanya jika file berasal dari sumber yang kamu percaya. Ini konfirmasi untuk DuoChat; tidak perlu mematikan Gatekeeper.

  1. Buka file installer.

    Unduh file Windows x64 Setup.exe, kemudian jalankan.

  2. Periksa konfirmasi keamanan.

    Jika SmartScreen muncul, pastikan sumber unduhan benar dan periksa checksum di halaman rilis. Untuk file yang kamu percaya, pilih More info → Run anyway jika tersedia.

  3. Ikuti pemasangan.

    Selesaikan langkah installer, lalu buka DuoChat melalui Start Menu atau shortcut aplikasi.

  1. Unduh AppImage.

    Unduh AppImage melalui tombol di atas. Simpan DuoChat-0.1.5.AppImage ke folder pilihanmu.

  2. Izinkan file dijalankan.

    Buka terminal di folder tempat file disimpan, lalu jalankan:

    chmod +x DuoChat-0.1.5.AppImage
./DuoChat-0.1.5.AppImage

  3. Mau masuk menu aplikasi Fedora?

    Unduh install-fedora.sh dari halaman rilis v0.1.5, simpan bersama AppImage, lalu jalankan:

    bash install-fedora.sh

    Jika FUSE belum tersedia, coba AppImage dengan opsi --appimage-extract-and-run.

SETELAH TERBUKA

Pindai QR WhatsApp dan Telegram untuk masuk. Aktifkan tombol Izin di layanan yang ingin memakai kamera, mikrofon, atau notifikasi.

BEBERAPA HAL KECIL

Eh, satu lagi…

Ini aplikasi resmi WhatsApp atau Telegram?

Bukan. DuoChat adalah aplikasi independen yang menampilkan WhatsApp Web dan Telegram Web dalam satu jendela. Layanannya tetap milik masing-masing penyedia.

Bisa telepon dan video call?

Kamera dan mikrofon bisa diberi izin per layanan. Ketersediaan serta fungsi panggilan mengikuti dukungan versi web WhatsApp atau Telegram dan perangkatmu.

Chat saya disimpan di mana?

Sesi login disimpan lokal, terpisah untuk setiap layanan. DuoChat tidak menyediakan server chat sendiri; pesan tetap mengikuti sistem WhatsApp dan Telegram.
